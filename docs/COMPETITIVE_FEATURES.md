# Competitive Feature Benchmark

## Reference Platforms Considered

- REDCap
- Medidata Rave
- Castor EDC
- OpenClinica
- Florence eConsent/ePRO-style workflows

## Common Strengths in Existing Platforms

- Reliable eCRF capture
- Basic role/permission controls
- Study configuration tooling
- Data export for analysis

## Typical Gaps (Opportunity for Virivu)

1. **Fragmented patient media workflows**
   - many platforms require separate tools for video/photo capture

2. **Weak patient UX**
   - often coordinator-centric, not patient-first

3. **Limited AI-native operations**
   - sparse automation for notes, guidance, and quality checks

4. **Cross-project analytics friction**
   - siloed reporting and difficult multi-study views

5. **Modular extensibility gaps**
   - adding institution- or sponsor-specific modules is often slow

## Virivu Differentiation Targets

- Best-in-class patient app UX for forms + media capture
- Unified trial operations + analytics + AI assistant model
- Strong multi-site collaboration dashboards
- Module framework for sponsor/institution-specific extensions
- Faster setup time from protocol to first patient submission

## Feature Scorecard Template (for ongoing tracking)

Use the following dimensions to track competitive advantage:

- Setup speed
- Patient completion rate
- Coordinator workload reduction
- Data query resolution time
- Compliance audit readiness
- Total cost of ownership
